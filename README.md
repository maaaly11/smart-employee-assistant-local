# مساعد الموظف الذكي

## المقدمة
مساعد الموظف الذكي هو مشروع يهدف إلى تحسين الإنتاجية وزيادة الكفاءة في بيئة العمل. يقدم المساعد ميزات متعددة تساعد الموظفين في إدارة مهامهم والتواصل مع الفريق.

## الميزات
1. **إدارة المهام:** يمكن للمستخدمين إنشاء ومتابعة المهام الخاصة بهم بسهولة.
2. **التقويم:** يمكن للمستخدمين مراقبة مواعيدهم واجتماعاتهم.
3. **التواصل:** يتيح المساعد التواصل الفوري بين أعضاء الفريق.
4. **التكامل:** يتكامل مع خدمات خارجية مثل البريد الإلكتروني والتقويم.

## المتطلبات
- لغة البرمجة: Python
- مكتبات: Flask, SQLAlchemy

## كيفية التثبيت
1. استنساخ المستودع:
   ```bash
   git clone https://github.com/maaaly11/smart-employee-assistant-local.git
   ```
2. تثبيت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```

## الاستخدام
1. تشغيل التطبيق:
   ```bash
   python app.py
   ```
2. الانتقال إلى المتصفح:
   افتح متصفحك واذهب إلى `http://localhost:5000`.
